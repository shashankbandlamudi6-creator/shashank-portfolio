# QUESTIONED GOD — Shashank's Portfolio

This repository contains a single-project portfolio for **Questioned God**.

## Publish with GitHub Pages
1. Upload `index.html` and `Questioned_God_Producer_Pitch.pdf` to the repository root.
2. Open **Settings → Pages**.
3. Under Build and deployment, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then Save.
5. Wait for GitHub Pages to publish the site.

Before publishing, replace the contact placeholder in `index.html` with a professional email address.

This is a concept portfolio, not a claim that the project is already produced or that revenue is guaranteed.
